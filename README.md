# Second Hand — Frontend

React + Vite + Bootstrap 5.

## Ejecutar
```bash
npm install
npm run dev
```

## Estructura
- `src/components` componentes reutilizables
- `src/pages` vistas (una por ruta)
- `src/hooks` lógica reutilizable
- `src/services` acceso a datos (hoy mock, luego API REST)
- `src/styles` tokens y estilos
- `src/assets` logo y recursos (reemplazar `logo.svg` por el de Figma)
- `public/images/items` fotos de los artículos de prueba
